# Tool Hub — Investor Pitch Package

This folder contains the standard documents used to raise capital from angels, seed funds, and strategic investors.

---

## What Investors Typically Ask For

| Stage | Documents | Purpose |
|-------|-----------|---------|
| **First contact** | Executive Summary, Pitch Deck | Get a meeting in 2–5 minutes of reading |
| **First meeting** | Pitch Deck (presented) | Tell the story in 10–12 minutes |
| **Follow-up** | Investor Memo, Market Opportunity | Deep dive on thesis and timing |
| **Term sheet stage** | Financial Projections, Use of Funds, Unit Economics | Validate economics and capital efficiency |
| **Due diligence** | Data Room Checklist | Legal, technical, and commercial proof |

## Recommended Pitch Flow

```
1. Send 01_EXECUTIVE_SUMMARY.md  →  secure meeting
2. Present 02_PITCH_DECK.md      →  10–12 min + Q&A
3. Follow up with 03_INVESTOR_MEMO.md + 04_MARKET_OPPORTUNITY.md
4. On interest: 05–09 + live product demo (dashboard :3200)
5. Term sheet: 07, 08, 10 (data room)
```

## Customization Before Sending

Replace placeholders marked `[COMPANY]`, `[FOUNDER]`, `[ASK]`, and `[DATE]` with your actual details.

| Placeholder | Example |
|-------------|---------|
| `[COMPANY]` | Antier / Your company name |
| `[FOUNDER]` | CEO name |
| `[ASK]` | $1.5M seed |
| `[DATE]` | July 2026 |
